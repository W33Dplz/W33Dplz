# Socle Twin

Socle Twin is an ontology-first digital twin of a small company: a typed graph of its entities, a structured knowledge base of its rules and procedures, and one MCP gateway through which any AI agent queries both.

- Ingestion connectors hold read-only credentials, and the typology is closed per company.
- Claude does the extraction, the typing and the entity matching, and people validate what matters.
- The gateway is read-only by default. Every write is a proposed action that a person approves.

Socle Twin is in active build. Today each twin is built with Claude, hand in hand with our first clients and with Derivatives Academy, our first test case. In 2027 the same pipeline becomes a plug-and-play platform.
